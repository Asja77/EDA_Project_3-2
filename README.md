# 🏨 Прогнозирование рейтинга отеля на основе текстовых отзывов

## 🎯 Цель проекта

Основная цель этого проекта — разработать модель машинного обучения, способную с высокой точностью предсказывать оценку (`reviewer_score`), которую клиент поставит отелю, основываясь на текстовых отзывах и метаданных. Ключевая метрика качества — **MAPE (Mean Absolute Percentage Error)**.

## 📂 Структура проекта

-   `main.py`: Основной исполняемый скрипт, который запускает весь ML-пайплайн.
-   `/data/hotels_train.csv`: Обучающий набор данных (необходимо положить в папку `data`).
-   `/artifacts_v17/`: Папка, в которую сохраняются обученная модель (`full_model_pipeline.pkl`) и TF-IDF векторизатор.
-   `README.md`: Этот файл.

    Убедитесь, что файл `hotels_train.csv` находится в корне проекта.
    ```bash
    python main.py
    ```

## 🛠️ Ключевые этапы пайплайна

### 1. 🧹 Очистка данных
-   Удалены "пустые" отзывы, такие как "No Negative" и "No Positive", для более чистого текстового анализа.

### 2. 📊 Исследовательский анализ данных (EDA)
-   Проанализировано распределение целевой переменной `reviewer_score`, которое показало смещение в сторону высоких оценок (8-10).
-   Выявлены страны с наибольшим количеством отелей в выборке (Великобритания, Испания, Франция и др.).

### 3. ✨ Генерация признаков (Feature Engineering)
Проект использует комбинацию классических и продвинутых техник:
-   **Временные признаки**: `days_since_review` — количество дней, прошедших с момента отзыва.
-   **Категориальные признаки**: Извлечены тип поездки (`trip_type`), состав гостей (`guest_type`), страна отеля (`hotel_country`).
-   **Текстовые признаки (TF-IDF)**: Созданы признаки на основе частотности наиболее важных слов и биграмм в отзывах.
-   **🧠 Нейросетевые признаки (Sentiment Analysis)**: С помощью предобученной модели `cardiffnlp/twitter-roberta-base-sentiment-latest` для каждого отзыва (позитивного и негативного) были рассчитаны вероятности его эмоциональной окраски (positive, neutral, negative). На их основе создан интегральный признак `sentiment_balance`.

### 4. 🤖 Обучение модели
-   В качестве основной модели был выбран **CatBoostRegressor**, так как он отлично работает с разнородными данными (числовыми и категориальными) и устойчив к переобучению.
-   Весь процесс предобработки (масштабирование, кодирование) и обучения обернут в `Scikit-learn Pipeline` для удобства и предотвращения утечек данных.
